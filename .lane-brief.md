## Problem
The board starts each task agent (and reviewer) as a Herdr classic pane via the herdr 0.9 socket/CLI (crates/core/src/herdr/*, crates/flow/src/delegate/launch.rs start_agent). Herdr classic is legacy; Luke only sees the Herdr app, which shows herdr-core terminals. When we move an agent to hc by hand, the board loses the mapping: task shows stopped, review/merge stop firing.

## Goal
A setting (e.g. `agents.runtime` = classic | hc, default classic so upstream behaviour is unchanged; Luke's board will set hc) under which every agent the board starts (task agent, reviewer, coordinator if it launches one the same way) is an hc terminal:
  hc run --bg --no-parent --keep --cwd <worktree> --name <task id dashed> --label herdr.space=<space id> [--label herdr.tab=<tab>] --label where="<Space> / <id>" --label herdr-projects.task=<id> <argv>
and the board's whole agent lifecycle works through hc: start, send prompt (hc send; then hc keys enter if still pending), read output/turn end (hc read / hc wait / hc get status: working|idle|done|blocked|exited), stop (hc interrupt / kill+rm), close on finish. The board must keep its mapping (store the hc terminal address/name instead of a pane id) so turn-ended detection, review and merge fire exactly as for classic panes.
Space: one Herdr app space per project (reuse by name; create with `herdr-app do space.new --name <project> --folder <repo>` only if missing; find with `herdr-app ls` JSON .spaces[].{id,name}). If herdr-app is not running, still start the hc terminal (unlabelled space is acceptable fallback) and log it.

## Facts
- hc binary: ~/.local/bin/hc (herdr-core 0.1.x). `hc --help`, `hc <cmd> --help`, `hc --skill` are authoritative. Commands: run, ls --all --json, get <t> (json: address,name,argv,cwd,labels,pid,status.state), read <t> --lines N, send <t> <text>, keys <t> enter, wait <t> --timeout S, interrupt <t>, kill <t>, rm <t>.
- Gotcha seen today: `hc send` to a just-booted pi can leave the text in the editor un-submitted; follow with `hc keys <t> enter` (harmless on an empty editor).
- Gotcha: hc spawns argv without the user's shell PATH; use an absolute program path (resolve with which at launch time).
- herdr-app: `herdr-app ls` (JSON), `herdr-app do space.new --name N --folder D`, `herdr-app do tab.rename --id <tab> --name N`.
