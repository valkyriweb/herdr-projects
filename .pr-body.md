## Why

Board agents currently start in classic panes, which are not visible in the Herdr app. Add the opt-in board setting `agents.runtime = classic | hc` (default `classic`) without replacing the existing review/merge state machine.

## Design and operation mapping

- Task links store `hc://local`; `link.pane`/`link.tab` reference a durable board place under the data folder's `hc/`. Its record keeps the real hc name, working folder, environment, kind and logical ownership group. Existing classic and hc links keep their runtime when the launch setting changes. The board's classic socket and UI hooks do not change.
- Start workers, reviewers and Coordinators with `hc run --json --bg --no-parent --keep --cwd ... --name ... --label herdr.space=... --label herdr.tab=... --label where=... --label herdr-projects.task=... -- /usr/bin/env ... <absolute executable> <args>`. Resolve executables on the board's PATH, not hc's shell PATH.
- Prompt with `hc send`; send a recovery Enter only when the terminal remains idle with unchanged `turn` and `status_ms`. A fast completed turn gets no second submission.
- Read output with `hc read`; reconcile `hc get`'s status, numeric timestamp/turn, address and finished state through the existing keeper and finish pipeline.
- Interrupt with `hc interrupt`. Terminate with `hc keep --off` and `hc kill`; wait until finished or missing before `hc rm`. Missing terminals are safe during cleanup and restart.
- Use native `git worktree add/remove`. Reuse app spaces by canonical project folder before display name; each agent gets its own stable labelled tab. Cleanup removes only owned terminals, not shared app spaces. An unavailable app permits a launch without a space label and logs the fallback.

## Explicit limitations / unmapped operations

- Classic focus/zoom/layout, popup/plugin panes, terminal takeover and pane moves: unsupported; use `hc attach` for interactive access.
- Typing an unsubmitted draft and arbitrary shell-prompt commands: explicit unsupported errors.
- Read-only planner mounts currently require the classic shell-launch path and fail closed on hc.
- Classic sidebar metadata is not forwarded. Labels group app tabs; board tab renames update saved metadata only.
- hc has no classic foreground-process-group query. Helper safety uses hc state and the existing transcript/helper checks.
- A real hc/app model-agent launch remains an unverified acceptance check.
